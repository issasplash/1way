# Инструкции для Claude Code

## Язык общения

- Всегда отвечай пользователю на русском языке.
- Сообщения о статусе, краткие итоги и пояснения пиши по-русски.
- Текст внутри кода (имена переменных, идентификаторы, технические термины фреймворков) оставляй на английском, как принято.
- Сообщения коммитов и описания PR — по-русски, если пользователь не попросил иное.
